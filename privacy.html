Política de Privacidade

Última atualização: 20 de agosto de 2026

1. Introdução

Este aplicativo utiliza a API da Biblioteca de Anúncios do Facebook para fins de pesquisa e análise de anúncios públicos.

2. Coleta de Dados

Este aplicativo NÃO coleta, armazena ou compartilha dados pessoais dos usuários.

3. Uso dos Dados

Os dados obtidos através da API são utilizados exclusivamente para:

  • Pesquisa de anúncios públicos
  • Análise de conteúdo publicitário
  • Fins acadêmicos e de estudo

4. Compartilhamento de Dados

Não compartilhamos dados com terceiros.
